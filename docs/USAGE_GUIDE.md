# Руководство по использованию Morse CLI

**Русский** | [English](USAGE_GUIDE.en.md)

## Описание

Модуль `morse_cli.py` - единый интерфейс командной строки для работы с декодером Морзе. Поддерживает автонастройку параметров, пакетную обработку, декодирование с конфигами и анализ процедурных кодов.

## Команды

### ✅ Доступные команды:
1. **auto** - автоматическая настройка параметров для файла
2. **batch** - пакетная обработка папки с многопоточностью
3. **decode** - декодирование с параметрами из .config.json
4. **procedural** - анализ процедурных кодов в декодированных текстах
5. **experiment** - экспериментальный поиск оптимальных параметров

### 🎯 Возможности:
- Автоматическая настройка параметров (fast/thorough/extreme)
- Пакетная обработка с многопоточностью (--workers)
- Загрузка параметров из .config.json
- Автоматическое определение языка (EN/RU)
- Поиск позывных через API (--lookup-callsigns)
- Поиск процедурных кодов (Q-коды, prosigns, сокращения)
- Создание подробных TXT отчетов и JSON конфигов

## Использование

### 1. Команда AUTO - автонастройка параметров

```powershell
# Быстрый режим (12 комбинаций, ~10 сек)
python morse_cli.py auto "file.wav"

# С поиском позывных
python morse_cli.py auto "file.wav" --lookup-callsigns

# Тщательный режим (560 комбинаций, ~7 мин)
python morse_cli.py auto "file.wav" --mode thorough

# Экстремальный режим (4752 комбинации, ~1 час)
python morse_cli.py auto "file.wav" --mode extreme
```

### 2. Команда BATCH - пакетная обработка

```powershell
# Обработать всю папку (однопоточно)
python morse_cli.py batch TrainingData

# С многопоточностью (4 потока)
python morse_cli.py batch TrainingData --workers 4

# С поиском всех позывных
python morse_cli.py batch TrainingData --lookup-callsigns --workers 4

# Тщательный режим для всей папки
python morse_cli.py batch TrainingData --mode thorough
```

### 3. Команда DECODE - декодирование с конфигом

```powershell
# Загрузить параметры из file.config.json
python morse_cli.py decode "file.wav"

# Указать путь к конфигу
python morse_cli.py decode "file.wav" --config custom.config.json

# С анализом процедурных кодов
python morse_cli.py decode "file.wav" --analyze
```

### 4. Команда EXPERIMENT - экспериментальный поиск

```powershell
# 30 итераций (по умолчанию)
python morse_cli.py experiment "file.wav"

# 50 итераций
python morse_cli.py experiment "file.wav" --iterations 50
```

## Аргументы командной строки

### Команда AUTO

| Аргумент | Тип | Описание | Значения |
|----------|-----|----------|----------|
| `file` | строка | Путь к WAV-файлу | обязательный |
| `--mode` / `-m` | строка | Режим настройки | `fast` (default), `thorough`, `extreme` |
| `--lookup-callsigns` / `--lookup` | флаг | Поиск позывных через API | - |

### Команда BATCH

| Аргумент | Тип | Описание | Значения |
|----------|-----|----------|----------|
| `folder` | строка | Путь к папке с WAV-файлами | обязательный |
| `--mode` / `-m` | строка | Режим настройки | `fast` (default), `thorough`, `extreme` |
| `--lookup-callsigns` / `--lookup` | флаг | Поиск позывных через API | - |
| `--workers` / `-w` | число | Количество потоков (0=автовыбор) | default: 0 |

### Команда DECODE

| Аргумент | Тип | Описание | Значения |
|----------|-----|----------|----------|
| `file` | строка | Путь к WAV-файлу | обязательный |
| `--config` / `-c` | строка | Путь к .config.json | default: file.config.json |
| `--analyze` / `-a` | флаг | Анализ процедурных кодов | - |

### Команда EXPERIMENT

| Аргумент | Тип | Описание | Значения |
|----------|-----|----------|----------|
| `file` | строка | Путь к WAV-файлу | обязательный |
| `--iterations` / `-n` | число | Количество итераций | default: 30 |

### Пакетная обработка


## Режимы автонастройки

| Режим | Комбинаций | Время | Когда использовать |
|-------|------------|-------|-------------------|
| **fast** | 12 | ~10 сек | Обычная обработка, быстрый результат |
| **thorough** | 560 | ~7 мин | Сложные записи, нужна точность |
| **extreme** | 4752 | ~1 час | Очень сложные сигналы, максимальная точность |

## Советы

1. **Начинайте с fast режима** - в 90% случаев достаточно
2. **Используйте decode** для повторной обработки с теми же параметрами
3. **Включайте --lookup-callsigns** только когда нужна информация о позывных (замедляет обработку)
4. **Многопоточность** ускоряет batch обработку в 3-4 раза
5. **Проверяйте .config.json** - там сохранены лучшие параметры

## Технические детали

### Определение качества

```python
quality = 100 - (количество '?' / общее количество символов) * 100
```

### Выбор языка

Декодер пробует EN и RU, выбирает язык с меньшим количеством ошибок (`?`).

### Поиск позывных

- Источники: HamQTH, RadioQTH, APRS.fi, QRZ.RU
- Кэширование в `callsign_cache/`
- Ограничение: 10 позывных на файл (производительность)
