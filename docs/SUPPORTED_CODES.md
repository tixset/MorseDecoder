## 📋 Общая информация

Декодер поддерживает обширную базу международных и российских процедурных кодов, используемых в радиосвязи. Все коды распознаются автоматически с поддержкой нечёткого поиска (fuzzy matching) для компенсации ошибок декодирования.

**Всего поддерживается:** 250+ кодов и символов

---

## 🔍 Особенности распознавания

### Нечёткий поиск (Fuzzy Matching)

Декодер использует алгоритм нечёткого поиска для компенсации ошибок декодирования:
- Допускается 1-2 ошибки в коде
- Учитывается контекст сообщения
- Вычисляется уровень уверенности (confidence)

**Пример:**
- `QRZ` → распознаётся даже как `QR?`, `?RZ`, `QBZ`
- `SK` → распознаётся даже как `S?`, `?K`

### Автоматическое определение языка

Декодер анализирует текст на английском и русском языках, выбирая вариант с меньшим количеством ошибок.

### Структурный анализ

Определяется тип сообщения по наличию характерных кодов:
- **Процедурная команда** - содержит Z/Y-коды
- **Оперативное сообщение** - содержит Q-коды
- **Экстренное** - содержит SOS, MAYDAY
- **Общая связь** - содержит позывные и prosigns

## 🔧 Использование в коде

```python
from modules.procedural_codes import ProceduralCodeDetector

# Создать детектор с нечётким поиском
detector = ProceduralCodeDetector(use_fuzzy_matching=True, max_errors=1)

# Анализировать текст
detected = detector.detect_codes("CQ CQ DE R1ABC QRZ K")

# Вывести результаты
print(detector.format_analysis(detected))
```
