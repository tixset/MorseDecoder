# История изменений

**Русский** | [English](CHANGELOG.en.md)

Все значимые изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [1.1.0] - 2026-01-07

### Добавлено
- ⚡ **Оптимизация производительности**
  - LRU кэширование (`@lru_cache(maxsize=1024)`) для функций fuzzy matching
  - Асинхронный поиск позывных ([modules/callsign_lookup_async.py](modules/callsign_lookup_async.py))
    - Использование aiohttp для параллельных запросов
    - Ускорение в 13 раз: 12.02 сек → 0.92 сек на 6 позывных
  - Numba JIT компиляция расстояния Левенштейна ([modules/levenshtein_optimized.py](modules/levenshtein_optimized.py))
    - Производительность: 326,394 операций/сек

- 🏗️ **Рефакторинг структуры кода**
  - Создан [modules/code_dictionaries.py](modules/code_dictionaries.py)
    - Централизованное хранилище всех словарей кодов (440 строк)
    - 18 словарей: Q_CODES, Z_CODES, Y_CODES, PROSIGNS, CW_ABBREVIATIONS и др.
  - Сокращён [modules/procedural_codes.py](modules/procedural_codes.py) с 1080 до 752 строк (30% уменьшение)
  - Устранено дублирование DXCC_PREFIX_MAP между модулями

- 🧪 **Инструменты проверки качества**
  - Скрипт проверки всех словарей кодов
  - Автоматическое тестирование распознавания 10 типов кодов
  - Верификация использования всех 18 словарей в детекторе

### Изменено
- 📊 Улучшена модульность: разделение данных и логики
- 🔧 Импорты обновлены во всех модулях для использования code_dictionaries

### Исправлено
- 🐛 Устранены циклические зависимости между модулями
- 🐛 Исправлены импорты после рефакторинга

## [1.0.0] - 2026-01-06

### Добавлено
- 🎯 **Расширенная аналитика сигналов** ([modules/signal_analyzer.py](modules/signal_analyzer.py))
  - Определение типа модуляции (CW/PSK31/RTTY) с уровнем уверенности
  - Анализ чистоты сигнала: chirp, clicks, noise_level, SNR, QRM
  - Оценка мастерства оператора: timing stability, rhythm consistency, dot/dash ratio
  - Автоматическая интерпретация результатов на русском языке
  - Вывод расширенной аналитики в TXT отчеты с emoji

- 📡 **Multi-signal декодирование** ([modules/multi_signal_decoder.py](modules/multi_signal_decoder.py))
  - Автоматическое определение множественных параллельных сигналов
  - Частотное разделение (300-1500 Hz, настраиваемый диапазон)
  - Умное детектирование: одиночный сигнал vs множественные
  - Предупреждения о ложных разделениях (гармоники, артефакты)
  - Параметр `--max-signals` для контроля количества
  - Полный отчёт сравнения: [docs/AUTO_VS_MULTI_COMPARISON.md](docs/AUTO_VS_MULTI_COMPARISON.md)

- 🔤 **Различение знака вопроса и ошибок декодирования**
  - Нераспознанные символы морзе: □ (U+25A1, белый квадрат)
  - Настоящий знак вопроса: ? (морзе код: ··--··)
  - Обновлён подсчёт ошибок во всех модулях
  - Добавлены пояснения в README и TXT отчёты

- 📁 **Улучшенная организация проекта**
  - Папка `docs/` для всей документации
  - Обновлённый `.gitignore` с полным списком исключений
  - Файл `CONTRIBUTING.md` с руководством для контрибьюторов
  - Актуальный `CHANGELOG.md`

### Изменено
- ⚡ Оптимизирован fast режим: 12 комбинаций вместо 560
- 📈 Улучшена оценка WPM: медиана длительности вместо минимума
- 🎨 Расширенный формат TXT отчётов: 8 детальных секций
- 🔧 Частотный диапазон multi режима: ограничен до 300-1500 Hz
- 📊 Улучшена визуализация результатов с emoji и форматированием

### Исправлено
- 🐛 Корректная обработка позывных с символом (?)
- 🐛 Правильный подсчёт ошибок (□ вместо ?)
- 🐛 Исправлен ключ SNR в выводе (snr_estimate вместо snr)
- 🐛 Улучшено определение одиночного сигнала (3+ пика в узком диапазоне)
- 🐛 Исправлено автоопределение частоты (2560 Hz → 600 Hz)

### Удалено
- 🗑️ Устаревшие отчёты: *_REPORT.md, *_SUMMARY.md, *_ANALYSIS.md
- 🗑️ Временные тестовые файлы: comparison_test/, code_analysis_results.json
- 🗑️ Вспомогательные скрипты: batch_multi_test.py, compare_auto_vs_multi.py, generate_report.py

## [0.9.0] - 2025-12-20

### Добавлено
- 📁 Единый CLI интерфейс [morse_cli.py](morse_cli.py)
  - `auto` - автоматический подбор параметров (fast/thorough/extreme)
  - `batch` - пакетная обработка с многопоточностью
  - `decode` - декодирование с готовыми параметрами
  - `experiment` - экспериментальный поиск

- 📊 Модульная архитектура в папке `modules/`
  - auto_tune.py - автоподбор параметров
  - morse_decoder.py - базовый декодер
  - procedural_codes.py - детектирование Q/Z-кодов, prosigns
  - fuzzy_matcher.py - нечёткое сопоставление с расстоянием Левенштейна
  - callsign_lookup.py - поиск через 4 API (HamQTH, RadioQTH, QRZ.RU, APRS.fi)

- 📝 Полная документация
  - README.md - основная документация с примерами
  - USAGE_GUIDE.md - подробное руководство пользователя
  - SUPPORTED_CODES.md - 280+ поддерживаемых кодов
  - PROJECT_CONTEXT.md - архитектура и контекст проекта

- 🧪 Универсальные тесты [run_tests.py](run_tests.py)

### Изменено
- Улучшена обработка шумных сигналов
- Оптимизирован полосовой фильтр (400-1200 Hz)

## [0.8.0] - 2025-11-15

### Добавлено
- Базовый декодер морзе-кода
- Поддержка английского и русского языков
- Распознавание Q-кодов (QRZ, QTH, QSL и др.)
- Распознавание Z-кодов (советские команды)
- Распознавание prosigns (AR, SK, BT, CT, KN и др.)

### Особенности
- Адаптивная настройка под скорость передачи (5-100 WPM)
- Поддержка форматов: WAV, MP3, OGG
- Автоконвертация через FFmpeg

## Формат версий

Проект следует [семантическому версионированию](https://semver.org/lang/ru/):
- **MAJOR** - несовместимые изменения API
- **MINOR** - новая функциональность с обратной совместимостью
- **PATCH** - исправления ошибок с обратной совместимостью

## Типы изменений

- `Добавлено` - новые функции
- `Изменено` - изменения в существующей функциональности  
- `Устарело` - функции, которые скоро будут удалены
- `Удалено` - удалённые функции
- `Исправлено` - исправления ошибок
- `Безопасность` - исправления уязвимостей
