# Вклад в проект MorseDecoder

**Русский** | [English](CONTRIBUTING.en.md)

Спасибо за интерес к проекту! Мы приветствуем любой вклад в развитие декодера азбуки Морзе.

## 📋 Как внести вклад

### 1. Сообщение об ошибках

Если вы нашли ошибку:
- Проверьте, не была ли она уже сообщена в [Issues](https://github.com/yourusername/morseDecoder/issues)
- Создайте новый issue с описанием:
  - Шаги для воспроизведения
  - Ожидаемое поведение
  - Фактическое поведение
  - Версия Python и ОС
  - Пример аудиофайла (если возможно)

### 2. Предложения по улучшению

- Откройте issue с тегом `enhancement`
- Опишите предлагаемую функцию
- Объясните, почему это будет полезно

### 3. Pull Requests

1. **Fork** репозитория
2. Создайте **ветку** для вашей функции:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Commit** изменения:
   ```bash
   git commit -m 'feat: Add amazing feature'
   ```
4. **Push** в ветку:
   ```bash
   git push origin feature/amazing-feature
   ```
5. Откройте **Pull Request**

## 🔧 Рекомендации по коду

### Стиль кода
- Следуйте PEP 8
- Используйте понятные имена переменных
- Добавляйте docstrings для функций и классов
- Комментируйте сложную логику

### Тестирование
- Запустите тесты перед отправкой PR:
  ```bash
  python run_tests.py
  ```
- Добавьте тесты для новой функциональности
- Убедитесь, что все тесты проходят

### Структура коммитов
Используйте Conventional Commits:
- `feat:` - новая функция
- `fix:` - исправление ошибки
- `docs:` - изменения в документации
- `refactor:` - рефакторинг кода
- `test:` - добавление/изменение тестов
- `chore:` - рутинные задачи

Примеры:
```
feat: Add support for RTTY modulation detection
fix: Correct SNR calculation in signal analyzer
docs: Update README with installation instructions
```
